# iOS 播放页增强功能开发记录 (控制面板与画中画)

## 功能概览
为 iOS 接收端（`ReceiveView`）开发了全新的控制面板和多画面支持，现在可以完美地进行音视频交互和复杂的画中画（PiP）操作了。

## 详细功能列表

### 1. 悬浮控制面板
在屏幕底部的居中位置，新增了磨砂质感的半透明控制面板，包含三个快捷操作按钮：
*   **扬声器开关**：点击后静音或开启从网页端接收到的声音（默认开启）。
*   **麦克风开关**：点击后静音或开启本地麦克风收音并传送给网页端（默认静音）。
*   **挂断退出**：点击后直接挂断连接并退出当前页面，替换了原本在左上角的简陋关闭按钮。

### 2. 双向语音音频支持 (`WebRTCManager`)
*   **本地采集**：在 `WebRTCManager` 中新增了 `setupLocalAudio()`，使用 `RTCDefaultAudioDeviceModule` 创建了本地麦克风轨道，并在呼叫建立前加入 PeerConnection，实现了将手机麦克风声音发送到网页端的能力。
*   **轨道控制**：新增了 `enableLocalMicrophone()` 和 `enableRemoteSpeaker()` 控制开关，可以实时动态开关相关音频流。
*   **权限检查**：经检查，您的 `Info.plist` 中已经妥善配置了 `NSMicrophoneUsageDescription` 权限说明，故无需修改。

### 3. 画中画 (Picture-in-Picture)
*   **智能布局**：当只收到一路视频（如单纯屏幕共享）时，全屏显示。当收到两路视频（如屏幕共享 + 摄像头）时，自动触发一大一小的画中画模式。
*   **自由拖拽 (`DragGesture`)**：小画面 `DraggablePiPView` 可以被手指自由拖拽到屏幕的任意位置，不再固定遮挡画面死角。
*   **双指缩放 (`MagnificationGesture`)**：可以双指捏合或放大来改变小画面的尺寸，支持在 0.5x 到 2.5x 之间无缝缩放。
*   **点击切换主副视角 (`TapGesture`)**：只需轻点小画面，小画面的视频流（如摄像头）会和全屏大画面（如桌面）瞬间对调，方便关注不同的画面细节。
