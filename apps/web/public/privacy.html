隐私政策

生效日期：2026年5月27日

Eastlake Studio（以下简称"我们"）重视您的隐私。本隐私政策旨在说明 CastNow 应用（以下简称"本应用"）在您使用过程中如何收集、使用、存储和保护您的信息。请您仔细阅读以下内容。

1. 信息收集与使用

本应用的核心功能基于端到端 (P2P) 点对点连接技术实现。在您使用本应用时：

  • 媒体流数据：您的视频画面（屏幕共享或摄像头）和音频数据通过 WebRTC 协议直接在投屏设备与接收端之间加密传输，不会经过、存储或转发至我们的任何服务器。
  • 信令数据：建立 P2P 连接所需的信令数据（如设备配对码、网络信息）通过 PeerJS 信令服务器进行临时中转，该过程仅在连接建立期间有效，不会持久化存储。
  • 崩溃与性能数据：我们可能收集匿名的应用崩溃日志和使用统计，仅用于改进产品稳定性和用户体验，不包含任何个人身份信息。

2. 我们不收集的信息

我们明确声明不收集以下信息：

  • 个人身份信息（姓名、邮箱、电话号码等，除非您主动联系支持）
  • 账户凭证或密码
  • 位置数据
  • 通讯录、照片或其他设备本地数据
  • 屏幕活动日志或键盘输入记录

3. 权限说明

本应用在 iOS 上需要以下系统权限，均仅用于实现核心投屏功能：

  • 摄像头：仅在您选择"摄像头投屏"模式时使用，用于捕捉视频画面。
  • 麦克风：仅在您开启麦克风共享时使用，用于传输音频。
  • 本地网络：用于在局域网内建立 P2P 连接，提升传输速度。
  • 屏幕录制（ReplayKit）：仅在您选择"屏幕共享"模式时使用，用于捕获屏幕内容。

以上权限均需您主动授权，您可以随时在系统设置中关闭。

4. 信息共享

由于我们不收集任何个人信息，因此不存在与第三方共享、出售或交易用户数据的情形。我们也不向广告商或其他商业实体提供任何用户数据。

5. 数据安全

我们采用以下措施保护您的数据安全：

  • P2P 传输采用 WebRTC 标准的 DTLS-SRTP 加密协议
  • 信令通信通过加密的 WebSocket (WSS) 连接
  • 应用代码遵循 Apple App Store 安全审核标准

6. 儿童隐私

本应用不面向 13 岁以下儿童。我们不会故意收集儿童的个人信息。如发现误收集，请及时联系我们以便删除。

7. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面公布，重大变更将通过应用内通知或更新说明告知。请定期查阅以了解最新内容。

Privacy Policy

Effective Date: May 27, 2026

Eastlake Studio ("we", "us", or "our") respects your privacy. This Privacy Policy explains how the CastNow application ("the App") collects, uses, stores, and protects your information while you use it. Please read the following carefully.

1. Information Collection and Use

The core functionality of the App is built on end-to-end peer-to-peer (P2P) connection technology. When you use the App:

  • Media stream data: Your video (screen sharing or camera) and audio data are transmitted via the WebRTC protocol, encrypted directly between the broadcasting device and the receiver. They are never routed through, stored on, or forwarded to any of our servers.
  • Signaling data: Signaling data required to establish a P2P connection (such as device pairing codes and network information) is temporarily relayed through a PeerJS signaling server. This occurs only while the connection is being established and is never persisted.
  • Crash and performance data: We may collect anonymous crash logs and usage statistics solely to improve product stability and user experience. These contain no personally identifiable information.

2. Information We Do Not Collect

We explicitly state that we do NOT collect the following:

  • Personally identifiable information (name, email, phone number, etc., unless you contact support proactively)
  • Account credentials or passwords
  • Location data
  • Contacts, photos, or other on-device data
  • Screen activity logs or keystroke records

3. Permissions

The App requires the following system permissions on iOS, all used solely for core casting features:

  • Camera: Used only when you select "Camera Broadcast" mode, to capture video.
  • Microphone: Used only when you enable microphone sharing, to transmit audio.
  • Local Network: Used to establish P2P connections over the local network for faster transmission.
  • Screen Recording (ReplayKit): Used only when you select "Screen Sharing" mode, to capture screen content.

All of these permissions require your explicit consent and can be revoked at any time in system Settings.

4. Information Sharing

Because we collect no personal information, there is no scenario in which user data is shared with, sold to, or traded with third parties. We do not provide any user data to advertisers or other commercial entities.

5. Data Security

We protect your data with the following measures:

  • P2P transmission uses the WebRTC-standard DTLS-SRTP encryption protocol
  • Signaling communicates over encrypted WebSocket (WSS) connections
  • The app code complies with Apple App Store security review standards

6. Children's Privacy

The App is not directed at children under 13. We do not knowingly collect personal information from children. If we discover such data has been collected inadvertently, please contact us so it can be deleted.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Updated policies will be published on this page, and material changes will be announced via in-app notices or release notes. Please review it periodically for the latest version.
